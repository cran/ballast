Validation summary

This vignette records how ballast was validated, for users who need to qualify it under their own procedures. The comparisons were made against two independent references: a SAS robustness package for a phase 3 trial (47 programs, run under SAS 9.4 and independently reviewed), ported program by program to R and checked cell by cell before the generic package was written; and rbmi, the reference R implementation of reference-based multiple imputation, on the public antidepressant data set it ships. Trial-level numbers from the SAS reference are not reproduced here; the comparison tables with every cell are held by the maintainer.

Tolerances

Deterministic quantities: estimate and standard error within 1e-6, degrees of freedom within 1e-3, p-value within 1e-8, AICc within 1e-4, numbers of subjects and observations exact. Monte Carlo quantities (multiple imputation, re-randomisation tests, MM-type robust regression with a random start): agreement within Monte Carlo error, judged by the standardised difference against the pooled Monte Carlo standard errors (|z| < 3).

Cross-check against rbmi

Reference-based imputation was compared with rbmi 1.7.0 on the antidepressant data (172 subjects, four visits, 80 missing values). Both engines used the same imputation model (treatment by visit, baseline, unstructured covariance common to the arms), the same number of bootstrap draws (100), the same intercurrent-event rule (the first missing visit after the last observed one), and the same analysis model applied to both sets of completed data sets, so the comparison isolates the imputation step.

The observed-data MMRM under MAR gave -2.87. One caution for rbmi users: rbmi::set_vars() adds only the main effects of group and visit, so the treatment-by-visit interaction must be named in covariates, or the imputation model understates late-visit contrasts.

Conventions needed to agree with SAS

  • DDFM=KR is mmrm’s method = "Kenward-Roger" with vcov = "Kenward-Roger-Linear"; mmrm’s full Kenward-Roger vcov gives a smaller standard error.
  • EMPIRICAL with Satterthwaite or KR falls back to between-within degrees of freedom, computed as observations minus subjects minus the rank of the within-subject design columns (sas_conventions = TRUE).
  • Least-squares means weight class covariates equally over their levels and set continuous covariates to their means.
  • AICc uses the SAS REML definition with the number of covariance parameters and N minus the rank of X.
  • A class covariate with one level in a subset is dropped from the model, as PROC MIXED zeroes it.
  • MNAR ADJUST under FCS adds the shift at every draw, so it propagates through later imputed visits.

Reproducibility

Every random-number-based family seeds per item (per imputation, per permutation) on the worker that draws it, so a result is the same for any number of cores. The run log written by stress_log() records the seed, the package and R versions, the platform and the MD5 hash of the plan text.

Test suite

R CMD check --as-cran passes with no errors or warnings on Windows, macOS and Linux (release and development R) on every push, through GitHub Actions. The unit tests use mmrm::fev_data and emmeans as an oracle for the least-squares-mean contrast.

# the tests can be run from an installed copy with
testthat::test_package("ballast")
